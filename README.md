# Graph Algorithms Benchmark

C++ implementation of Floyd–Warshall and Johnson's algorithm with a custom Fibonacci Heap implementation.

The program generates random sparse and dense graphs and benchmarks both algorithms.

## Build & Run

### GCC / MinGW

g++ -std=c++11 -O2 main.cpp -o graph_benchmark

./graph_benchmark

On Windows:

.\graph_benchmark.exe

Benchmark parameters (graph sizes, number of runs, edge weights) can be configured in main().
